# Test coverage

Jest unit coverage and Playwright end-to-end coverage are published with this documentation after CI runs on `main`.

Open a report to see covered and missed lines:

- [Jest unit test report](../coverage/jest/index.html)
- [Playwright end-to-end report](../coverage/playwright/index.html)
- [Jest totals on the unit test page](../unit-test.html)

A pull request also gets a coverage comment, and changed TypeScript files under 80% Jest line coverage are flagged on the coverage check.
